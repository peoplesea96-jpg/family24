# 가족 24 (Family24)

가족 구성원이 일정을 공유하고, 가능한 시간을 조율해 일정을 확정하는 가족 캘린더 프로젝트입니다.

## 현재 상태

- 실제 서비스 구현 미시작
- PRD·IA 의사결정 확정 (이전 기획 대화 기준)
- 정적 HTML 목업 존재: 예시 데이터로 화면과 일부 상호작용을 확인할 수 있습니다.
- PRD 원본 `family_calendar_prd_final.md`는 파일 확보 후 추가 예정입니다. 현재 저장소에는 포함되지 않았습니다.
- 최종 IA 문서 정리는 후속 작업입니다.

## 파일 설명

| 파일 | 설명 |
| --- | --- |
| `family_calendar_mockup.html` | 이전 대화에서 생성한 가족 캘린더 정적 목업 원본 |
| `index.html` | GitHub Pages 진입점용 목업 복사본 (원본과 동일) |
| `README.md` | 프로젝트 개요, 파일 설명, 현재 상태 |

## 목업 열기

`index.html` 또는 `family_calendar_mockup.html`을 브라우저에서 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

목업은 월간·주간 보기, 일정 검색·필터, 일정 상세 탭, 일정 생성 및 알림 화면을 포함합니다. 실제 로그인, 서버 연동, 데이터 저장 기능은 구현되지 않았으며, 목업에서 추가한 일정은 새로고침하면 사라집니다. 목업이 확정된 PRD·IA의 모든 요구사항을 반영하는 것은 아닙니다.

GitHub Pages로 공개하려면 저장소 **Settings → Pages**에서 **Deploy from a branch**, **main / (root)**를 선택합니다. `index.html` 준비만으로 Pages가 자동 활성화되지는 않습니다.
